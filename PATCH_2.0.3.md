# Патч 2.0.3: меню и прокси для вашей сборки

Подготовлен по `tgviewer-current-code.tar.gz` от 17 октября 2026. В этой сборке уже есть вход по номеру и коду с цифровой клавиатурой. Патч сохраняет его вместе с QR и импортом готовых сессий.

## Установка

Загрузите `telegram-channel-viewer-patch-2.0.3.zip` в `/root`. Выполните целиком:

```bash
patch_dir=$(mktemp -d /root/tgviewer-patch.XXXXXX)
unzip /root/telegram-channel-viewer-patch-2.0.3.zip -d "$patch_dir"
python3 "$patch_dir/tgviewer-patch-2.0.3/update.py" --instance tgviewer2
systemctl status tgviewer2.service --no-pager
```

Затем откройте `/menu` в боте. Установщик работает с системным Python 3.10; бот использует уже установленное окружение Python 3.12. Предыдущий патч 2.0.2 ставить не нужно.

## Что изменено

- Короткое главное меню, понятные названия и индикаторы состояния.
- Зелёные кнопки для запуска и добавления, синие для основных действий, красные для остановки и удаления. Отображение цветов зависит от приложения Telegram.
- Добавление находится внутри «Аккаунтов», доступы и диагностика — внутри «Настроек».
- Выбор прокси для аккаунта — кнопками, с подтверждением.
- Импорт SOCKS5/HTTP текстом или TXT: смешанные форматы, проверка строк, удаление дублей. При ошибке строки весь список отклоняется с указанием номера строки.
- Проверка прокси получает ответ MTProto через него без использования сессий аккаунтов. До 5 проверок одновременно, таймаут 12 секунд.
- Повторная загрузка прокси сохраняет назначения аккаунтов и отключённое состояние прокси. Изменённый пароль требует новой проверки.
- При одновременных подключениях автовыбор распределяет и закрепляет проверенные прокси последовательно. Недоступный закреплённый прокси не обходится напрямую.

## Сохранность аккаунтов

Сервис входа по коду и QR, хранение аккаунтов, шифрование, схема БД и зависимости сохранены из присланного кода без изменений. Патч меняет интерфейс и работу с прокси.

До остановки службы установщик сверяет исходный код с присланным архивом и проверяет импорт нового кода. Затем он останавливает только `tgviewer2.service`, создаёт дамп базы и закрытую копию настроек с текущим ключом шифрования. Все поля аккаунтов и расшифровка непустых сессий проверяются до и после подготовки обновления при остановленном боте. При несовпадении новый код не активируется.

Миграции, повторный импорт аккаунтов, выход из Telegram и смена ключа не выполняются. При ошибке переключения или запуска установщик возвращает предыдущий код. Ранее остановленная служба остаётся остановленной. После успешного запуска обычные задания бота продолжают работу.

Не удаляйте предыдущий релиз: новый использует его `.venv`. Путь предыдущего релиза и дампа установщик напечатает в конце. Базу поверх текущих данных при откате он не восстанавливает.

## Как добавить прокси

«Прокси → Добавить SOCKS5» или «Добавить HTTP». Отправьте текст или TXT, один прокси на строку:

```text
login:password@host:port
host:port:login:password
host:port
socks5://login:password@host:port
http://login:password@host:port
socks5://[2001:db8::1]:1080
```

Без префикса берётся тип выбранной кнопки; с префиксом — тип строки. Для реквизитов со специальными символами используйте URL и %-кодирование: `%40` для `@`, `%3A` для `:`, `%25` для `%`. Без префикса `%` остаётся обычным символом пароля.

Прокси без логина и пароля подходит для авторизации по IP: провайдер должен разрешать IP сервера. HTTP-прокси должен поддерживать CONNECT до Telegram. HTTPS, SOCKS4 и MTProxy не поддерживаются.

Нажмите «Проверить все», затем при необходимости назначьте прокси: «Аккаунты → аккаунт → Прокси → выбрать → Применить». Успешная проверка одного дата-центра не проверяет сессию аккаунта — для неё есть отдельная кнопка в карточке аккаунта.

## Проверки

Локально проверяются меню, оба способа входа, защита цифровой клавиатуры, форматы и локальный SOCKS5/HTTP-протокол, MTProto-ответ, неизменность сессий при действиях с прокси и откат установщика. Реальные аккаунты для тестов не используются. PostgreSQL-интеграционные тесты без тестового PostgreSQL пропускаются. Установка на вашем сервере выполняется командами выше.

Если установщик сообщил об отличиях исходного кода, пришлите текст ошибки. Если служба не запускается:

```bash
journalctl -u tgviewer2.service -n 60 --no-pager
```

Файл настроек, дамп базы, пароли и сессии присылать не нужно.
