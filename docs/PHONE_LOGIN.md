# Добавление по номеру и коду

Обновление для Telegram Channel Viewer 2.0.1, 17 октября 2026.

В личном чате главного администратора откройте `/menu` → «Добавить аккаунты» →
«По номеру и коду». Отправьте номер в международном формате, например
`+79991234567`, затем нажмите «Добавить по коду».

Бот запросит код у Telegram и укажет способ его доставки. Наберите код цифровыми
кнопками под запросом, затем нажмите «Войти». Кнопки «Стереть» и «⌫» исправляют
ввод; на экране показывается только количество набранных цифр. Если включён
пароль двухэтапной защиты, бот запросит его отдельно. После входа сохраняется
зашифрованная сессия, код и пароль не записываются в БД, файлы или результаты.

Не отправляйте и не пересылайте код сообщением: Telegram аннулирует такие коды.
Если это произошло, воспользуйтесь «Запросить новый код», когда закончится
период ожидания, либо начните добавление заново. Кнопка повторного запроса
появляется, когда Telegram допускает следующий способ доставки. Не больше
трёх запросов и трёх проверок кода на один вход. Лимит всего входа по умолчанию
пять минут, включая 2FA. SMS не гарантируется: способ доставки выбирает Telegram.

Официальное описание входа и аннулирования кодов:
https://core.telegram.org/api/auth#invalidating-login-codes

При загрузке списка номеров или ZIP с пустыми парными `.session` в предпросмотре
теперь можно выбрать «Добавить по коду» либо «Добавить по QR». Готовые сессии
по-прежнему импортируются без нового кода. В карточке существующего аккаунта
«Войти заново» предлагает оба способа. Неподдерживаемый Telegram способ доставки,
например настройка email или Firebase-подтверждение, вызывает понятную ошибку;
можно воспользоваться QR или готовой сессией.

«Пропустить аккаунт», «Остановить импорт» и `/cancel` прерывают ожидание.
Старые клавиатуры не подходят к новому запросу. Доступ к добавлению, как и в
2.0.1, есть только у главного администратора в личном чате.

Установка: загрузить `update_tgviewer_code.py` в `/root`, выполнить
`python3 /root/update_tgviewer_code.py`. По умолчанию используется служба
`tgviewer2.service`; другой экземпляр задаётся через `--instance имя`.
Проверка без записи и перезапуска: добавить `--check`.

Файл обновления работает на системном Python 3.10+ Ubuntu 22.04. Сам проект
использует уже установленное окружение Python 3.12+. Новые зависимости не нужны.
Проверяются исходные файлы, делается копия изменяемого кода в `/var/backups`,
останавливается и запускается только выбранная служба. Если она была остановлена,
такой статус сохраняется. При ошибке применения восстанавливается исходный код.
База данных, настройки, ключ шифрования и системные пакеты не изменяются.

Проверки выполнены с подменёнными ответами Telegram; реальные SMS, вход в ваш
аккаунт и применение systemd-обновления на вашем сервере не проверялись.
