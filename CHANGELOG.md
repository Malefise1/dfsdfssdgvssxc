# 2.0.1 — 2026-10-17

- Добавлен импорт пар `.session + .json` из tpanel.online и совместимых экспортёров.
- Номер в JSON теперь может быть записан без ведущего `+`.
- Пустая парная `.session` переводится в явное QR-подтверждение вместо отказа всего ZIP.
- Лимит массового импорта считается по аккаунтам, а не по числу sidecar-файлов.
- Бот показывает точную безопасную причину отказа файла и отдельно сообщает число пустых сессий.

# 2.0.0 — 2026-10-16

Переработано исполнение задач и управление ботом. Исправления соответствуют замечаниям аудита исходного архива 1.2.

| Пункты аудита | Реализация |
|---|---|
| 1–2 | Пауза и запрос отмены в БД; отдельное штатное завершение; возобновление по контрольным точкам |
| 3 | Общий контроллер сессий для заданий/подписок/проверок, семафор, блокировки аккаунта и экземпляра |
| 4–5 | Только личный чат, проверка роли на каждом действии, отключение прежнего владельца |
| 6–7 | План результатов до запуска, полный знаменатель отчёта, тест с чередованием каналов и корректным дедлайном |
| 8 | Отключение прерывает подключения; пауза 24/7 одного канала не отменяет остальные каналы задания |
| 9 | Обязательные прокси по умолчанию, стабильное назначение, явное разрешение прямого выхода |
| 10–11 | Строковые ячейки XLSX и удаление управляющих символов; cryptography 50.0.2; полный lock с хешами |
| 12 | Разделение ошибок авторизации/сети/канала, контрольные точки, архивирование и снимки данных отчёта |
| 13 | Отдельный срок хранения, объединённые напоминания, удаление после подтверждения и срока |
| 14 | 0700/0600, закрытый systemd-контекст, атомарные копии и state, pg_restore-проверка, отдельный тест восстановления, необязательное age-зеркало |
| 15 | Единые границы теста/очереди/импорта, строгий ключ Fernet, ограниченные загрузки, кодирование реквизитов прокси и обновление пароля |
| 16 | Страницы и поиск, фильтры, карточки, healthcheck, управление расписаниями, сводные отчёты |
| 17 | Явная миграция схемы, read-only doctor, отдельные установка/обновление/откат |
| 18 | Модули экранов и сервисов, журнал действий, состояние фоновых задач, очистка логов, XLSX вне event loop, регрессионные тесты и CI |

Дополнительно: одиночный QR-вход, 2FA с удалением сообщения до обработки, безопасный по ограничениям разбор файлов, массовое добавление с подтверждением и отчётом, история импорта, настройки каналов и телефонов менеджеров. Протоколы и ограничения импорта описаны в docs/ACCOUNTS.md.

База 1.2 обновляется добавлением полей и таблиц. Старые незавершённые задания отменяются явно. Старый ключ шифрования сохраняется. Серверная установка и вход с настоящими аккаунтами не выполнялись при подготовке архива.
